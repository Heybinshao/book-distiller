# 常见坑（维护者对照）

> 2026-08 路径模拟（path-simulation）发现并修复后沉淀。这些是维护本 skill 时容易再犯的坑类型，改文档/脚本时对照检查。

| 坑类型 | 表现 | 防法 |
|--------|------|------|
| 模板占位符漏列 | 模板正文用了 4 个占位符（含 {干净书名}），替换说明只列 3 个 → 主 agent 照说明替换后字面量原样下发 subagent | 改模板正文时，使用说明里的占位符清单必须与正文**一一对应**；新增占位符先更新说明 |
| 转换产物缺落位命令 | pandoc 输出 md 到当前工作目录，但流程要求放 `01｜书籍原文/`，只有路径描述没有 mv/cp 命令 | 转换命令后紧跟「移动到原文目录」的显式 mkdir+mv，不能只写目标路径 |
| 检查项漂移 | SKILL.md 声称「结构五件套」，quality_check.py 只验其中 2 件 → 脚本通过≠文档达标 | 改 SKILL.md 检查项时同步改 quality_check.py；反之亦然，两者必须一致 |
| 环境检测覆盖不全 | pdf 是支持格式，但环境检测只查 pandoc/python3/opencc，pdftotext 未装时方法 2 静默失败 | 每种支持格式的依赖都要进环境检测；可选依赖也要显式提示兜底路径 |
| 跨文件口径不一致 | 同一参数（如并行数 3 vs 5）在 SKILL.md 与 windows-adaptation.md 中值不同 | 跨文件提到同一参数时先 grep 全目录核对，值必须一致 |
| references 分支与主流程断链 | extraction-framework.md 定义「快速拆解」P0 模式，但 SKILL.md 主流程无对接 → 用户说「快速拆解」时 agent 无指引 | references 里新增用户可触发的分支时，主流程必须有对应入口；否则标注「未对接」 |
