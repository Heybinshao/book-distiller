# 书籍榨干方法论（彬少版）

> 判断一本书里什么值得提取，什么可以跳过。

---

## 一、核心原则

### 提取标准

一本书中，以下内容**必须提取**：

| 类型 | 说明 | 判断标准 |
|:----|:----|:---------|
| 核心命题 | 整本书想论证什么 | 作者在序言/开头明确说的 |
| 关键概念 | 作者定义的新术语/新概念 | 有明确命名且反复出现的 |
| 心智模型/框架 | 作者用的分析框架 | 有步骤/流程/图表的 |
| 案例 | 支撑论点的具体例子 | 有具体人/事/数据的 |
| 金句 | 表达精炼的原话 | 你读了想划线的 |
| 反模式 | 作者反对的做法 | 有「不要」「避免」「错误」标记的 |
| 行动清单 | 读完能做的事 | 有「建议」「步骤」「方法」的 |

以下内容**可以跳过**：

- 重复的车轱辘话（同一个观点翻来覆去说）
- 充篇幅的填充内容（与核心论点无关的逸事）
- 过时的数据/案例（如2010年的统计数据）
- 广告/推广内容（作者推荐自己的其他产品）

### 不要做的主观判断

- 不要替作者总结他「可能想说什么」——只提取明确说的
- 不要用自己的价值观评判对错——先完整提取，批判性审视单独列
- 不要因为某个概念「我觉得不重要」就跳过——你觉得不重要的可能以后有用

## 二、概念识别方法

### 2.1 正式概念 vs 随口一说

书里的概念不一定都是「概念」。区分方法：

| 特征 | 正式概念 | 随口一说 |
|:----|:--------|:---------|
| 有命名 | 「心流」「元认知」 | 「这个人很专注」 |
| 有定义 | 明确解释是什么 | 没解释，当常识用 |
| 反复出现 | 至少出现3次以上 | 只出现一次 |
| 有结构 | 有步骤/要素/分类 | 只是描述性语句 |

**正式概念 → 单独提取**。随口一说 → 如果搭配了好的案例或金句，保留；否则跳过。

### 2.2 跨章节追踪

同一个概念在不同章节出现时，要注意：

- 作者在不同语境下的解释是否一致
- 是否有拓展或修正
- 是否有实例补充

提取时应该合并同一概念的所有出现，而不是按章节分散记录。

### 2.3 隐含假设

有些概念作者没说但隐含在论证中。判断方法：

- 这个论点成立的前提是什么？
- 作者默认读者已经知道什么？
- 如果前提不成立，论点还成立吗？

隐含假设单独列出，标注「书中未明说，但隐含的前提」。

## 三、提取优先级

当书籍内容量大，时间有限时，按以下优先级提取：

```
P0 - 必提（不可跳过）
  核心命题、关键概念、心智模型/框架

P1 - 应提（尽量提取）
  金句、案例、反模式

P2 - 可选（有时间再提）
  行动清单、数据/引用、系列推荐
```

如果用户说「快速拆解」，只提 P0。如果用户说「完整拆解」，P0+P1+P2 全提。

---

## 四、常见提取陷阱

| 陷阱 | 表现 | 正确做法 |
|:----|:----|:---------|
| 过度概括 | 把3个不同概念合并成1个 | 每个概念独立列出，哪怕内容很少 |
| 个人偏好 | 只提取自己感兴趣的部分 | 按优先级提取，不选择性忽略 |
| 提前判断 | 「这个观点不对，不提取」 | 先完整提取，批判性审视单独列 |
| 转述替代 | 用自己的话概括原话 | 金句用原话，概念用书中原文定义 |
| 忽略论证 | 只提取结论不提取推理过程 | 把作者的论证链一起记下来 |
